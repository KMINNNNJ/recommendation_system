# 신규 사용자 스킨케어 추천: 평가 설계와 모델 개선

## 문제

리뷰나 구매 이력이 없는 신규 사용자는 사용자 ID 기반 개인화에 필요한 이력이 없다. 이 프로젝트는 피부 타입·피부톤·눈동자색·머리색만으로 추천을 시작하는 상황을 대상으로 한다. 목표는 신규 사용자가 긍정적으로 평가할 상품을 상위 10개에 배치하는 것이다.

## 데이터와 평가

Sephora 상품·리뷰 데이터에서 스킨케어 상품 2,420개를 사용했다. 원본 리뷰 1,094,411행의 분할본과 통합본을 전체 행 지문으로 대조하고, 동일 데이터를 중복 연결하지 않았다. 사용자–상품 중복 리뷰 5,525개를 정리하여 1,088,886개 리뷰와 503,216명의 사용자를 확보했다.

사용자를 학습 352,251명, 검증 75,482명, 테스트 75,483명으로 분리하여 사용자 중복을 방지했다. 검증·테스트는 각각 긍정 리뷰가 있는 사용자 3,000명·10,000명을 고정 샘플링했다. 한 개의 리뷰만 있는 사용자도 포함했다.

사용자 입력은 첫 유효 날짜의 리뷰에 기록된 프로필로 고정했다. 이는 실제 가입 설문을 대신하는 근사이며, 진짜 가입 시점 정보를 관측한 것은 아니다. 상품 전체 평점·전체 리뷰 수·리뷰 텍스트는 추천 모델 입력에서 제외했다. 인기도 기준 모델의 집계도 학습 사용자만 사용했다.

긍정 정답은 평점 4~5점이면서 추천 여부가 긍정 또는 결측인 리뷰다. 평점 1~2점이나 명시적 비추천은 부정으로 처리했고 나머지는 모호한 평가로 구분했다. 리뷰하지 않은 상품이 모두 싫은 상품이라는 의미는 아니다.

## 변경

원본 노트북의 학습 설정은 사용자 ID와 프로필을 함께 사용하며, 사용자당 긍정 2개·상품당 긍정 10개 필터, 64차원 임베딩과 원래 상품 feature를 사용했다. 신규 설정은 사용자 ID를 제외하고 단일 리뷰 사용자를 유지하며, 32차원 프로필 LightFM과 정리한 상품 feature를 사용했다. 상품 성분은 중복과 희귀 토큰을 정리하고 성분 그룹의 총 가중치를 일정하게 했다.

LightFM WARP 외에 인기도·평활화 기준 모델, 피부 타입 단독/ID 포함 비교, CatBoost·LightGBM 분류 모델을 포함한 8개 설정을 평가했다. 모델과 체크포인트는 검증에서 선택했다. 트리 모델과 LightFM은 목적 함수 및 입력 인코딩이 달라 이 실험만으로 알고리즘 자체의 우열을 확정하지 않는다.

원본 전체 데이터 모델은 테스트 사용자를 이미 학습했을 가능성이 있어 비교에 쓰지 않았다. 대신 원본 노트북의 feature·k-core·하이퍼파라미터를 공통 학습 사용자로 재현했다. 원본 20회·30회 설정을 고정 평가했으며 주 비교 대상은 기존 튜닝 설정인 30회다.

## 결과

같은 신규 사용자 10,000명, 같은 프로필 입력, 같은 스킨케어 후보·정답에서의 결과다.

| 설정 | Precision@10 | Recall@10 | NDCG@10 |
|---|---:|---:|---:|
| 학습 인기도 기준 모델 | 0.01568 | 0.10056 | 0.05862 |
| 원본 설정 재학습 · 30회 | 0.01933 | 0.10441 | 0.06200 |
| 개선 프로필 LightFM | **0.02178** | **0.13324** | **0.08388** |

원본 설정 재학습 대비 상대 향상은 Precision 12.67%, Recall 27.61%, NDCG 35.29%다. NDCG의 사용자별 평균 차이는 0.02188이며 사용자 단위 paired bootstrap 95% 구간은 [0.01924, 0.02458]로 양수였다. 이 구간은 학습 seed 변동까지 반영하지 않는다.

이는 여러 전처리·특징·학습 설정 변경을 합한 효과다. 사용자 ID 제거 등 특정 변경 하나가 35% 향상을 만들었다고 주장할 수 없다. 원본 노트북의 과거 무작위 리뷰 분할 점수와 직접 계산한 향상률도 아니다.

## 후속 실험: 실패와 부분 개선

관측된 긍정·부정 리뷰를 함께 사용하는 LightFM logistic 모델 두 가지를 추가 학습했다. 부정 가중치 0.25/1.0의 테스트 NDCG는 각각 0.01897/0.01451로 기존 WARP보다 낮아 채택하지 않았다. 이 설정의 결과이며, 부정 리뷰 활용 자체가 무효라는 결론은 아니다.

브랜드·성분 유사도 중복을 줄이는 재정렬도 비교했다. 검증 NDCG 하락을 2% 이내로 제한하며 상품 커버리지를 우선해 설정을 선택했다.

| 전체 후보 테스트 지표 | 재정렬 전 | 재정렬 후 |
|---|---:|---:|
| Precision@10 | 0.02178 | 0.02139 |
| Recall@10 | 0.13324 | 0.13480 |
| NDCG@10 | 0.083878 | 0.083854 |
| 평균 추천 브랜드 수 | 7.70 | 9.41 |
| 노출된 고유 상품 수 | 74 | 73 |

브랜드 중복은 감소했지만 NDCG 차이의 95% 구간은 [-0.00092, 0.00090]으로 0을 포함했다. 정확도 향상은 확인되지 않았고 전체 상품 노출 집중도 해결하지 못했다. 이 때문에 데모는 재정렬을 선택 기능으로 제공하고 기본값은 재정렬 전 개선 모델로 둔다.

후속 실험은 이전과 같은 검증·테스트를 재사용한 탐색이다. 독립적인 최종 검증을 대신하지 않는다. 종류별 평가는 해당 종류를 요청했다고 가정한 조건부 평가이며 실제 질의 로그를 평가한 것은 아니다.

## 구현과 검증

Streamlit 데모는 원본 설정 재학습 모델과 개선 모델을 같은 제품 종류·USD 예산·제외 성분 조건으로 비교한다. 모델은 프로세스에서 캐시하고, 기존 서비스/API와 별도로 동작한다. 전체 리뷰 파일, DB, 외부 LLM API 없이 저장된 모델·상품 feature로 실행한다.

신규 평가 실험, 후속 실험, 데모를 포함한 검증 18개가 현재 Python 3.11.9 환경에서 통과했다. Streamlit의 실제 앱 실행기로 폼 입력·추천 결과·빈 후보 화면을 확인했다. 전체 데이터 재학습을 이번 데모 마감에서 다시 반복한 것은 아니다.

로컬 서버를 실행한 브라우저에서도 건성·보습제·50 USD 조건의 원본/개선 비교를 확인하고 화면을 저장했다. 좁은 화면에서도 상품명·브랜드·가격이 보이도록 카드 형태로 표시했다.

Windows 네이티브 LightFM WARP 학습 중 발견한 signed 정수 변환 문제는 실험 전용 확장 모듈에서 수정했다. 원본 서비스나 시스템 설치본을 바꾸지 않았고 재학습 절차와 필요한 MSVC 빌드는 실행 안내에 기록했다.

## 남은 한계와 완료 범위

- 같은 4개 프로필과 같은 조건이면 같은 추천을 받는다. 피부 고민·예산·제형 취향의 학습 라벨은 없다. 예산과 성분 제외는 입력 필터로만 반영한다.
- 리뷰 작성자는 실제 신규 가입자 전체를 대표하지 않으며, 추천 점수는 효과·자극·만족도의 확률이 아니다.
- 시간순 분리가 아닌 사용자 분리이며 상품 정보는 정적 스냅샷이다. 신상품 일반화와 미래 시점 성능은 별도로 평가하지 않았다.
- 한 번의 분할과 seed를 사용했다. 병렬 학습 변동과 여러 seed에서의 안정성 검증은 남아 있다.
- 추천 노출은 2,420개 중 74개 상품에 집중됐다. 브랜드 다양성과 상품 전체 노출 다양성은 다르다.
- 기존 서비스 연결·온라인 A/B 평가·공개 배포는 수행하지 않았다. 데모는 로컬 실행 범위다.

완료 범위는 **신규 사용자 평가 설계, 원본 재현 비교, 오프라인 성능 개선, 실패 실험 분석, 로컬 비교 데모와 재현 안내**다. 다음 추가 실험이 필요하다면 여러 seed 재학습과 별도 사용자 평가를 우선한다.
