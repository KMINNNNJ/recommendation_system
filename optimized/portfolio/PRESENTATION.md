# 발표·면접 설명 예시

## 1분 설명

“리뷰 이력이 없는 신규 사용자에게 스킨케어 상품을 추천하는 프로젝트입니다. 기존 무작위 리뷰 분할에서는 학습에 있던 사용자가 평가에도 등장할 수 있어, 먼저 사용자가 겹치지 않는 평가를 만들었습니다.

약 109만 건의 리뷰에서 중복을 정리하고, 프로필만으로 추천하는 LightFM과 여러 기준 모델을 비교했습니다. 원본 설정도 같은 학습 사용자로 재학습하여 신규 사용자 1만 명에게 평가했습니다. 그 결과 NDCG@10을 0.0620에서 0.0839로 약 35% 개선했습니다.

부정 리뷰 모델은 성능이 낮아 제외했습니다. 다양성 재정렬은 브랜드 중복을 줄였지만 정확도나 전체 상품 노출 범위 개선으로 이어지지는 않았습니다. 이 차이를 문서화하고, 두 모델의 추천을 같은 조건으로 비교할 수 있는 로컬 데모를 만들었습니다.”

## 2분 시연

1. 데모에서 피부 타입 ‘건성’, 제품 종류 ‘보습제’, 예산 50 USD를 선택한다.
2. ‘추천 비교하기’를 눌러 원본 설정 재학습과 개선 모델 결과를 보여준다.
3. 추천 목록만으로 성능을 판단하지 않는다고 설명하고, 하단 ‘실험 결과와 해석’에서 같은 평가 조건의 수치를 보여준다.
4. ‘브랜드 중복 줄이기’를 켜서 목록 변화와 정확도 향상 미확인이라는 한계를 설명한다. 이 예시 입력에서 브랜드 수가 반드시 늘어나는 것은 아니다.
5. 결과 문서의 상품 쏠림·가입 설문 대리 입력·한 seed 한계를 보여준다.

## 질문에 답할 때

- **왜 LightFM인가?** 사용자 이력 없이 프로필과 상품 속성을 함께 사용할 수 있고 이번 공통 검증에서 선택됐다. 다른 알고리즘보다 항상 좋다는 주장은 하지 않는다.
- **35%는 무엇의 향상인가?** 원본 설정을 같은 학습 사용자로 다시 학습한 30회 모델 대비, 신규 사용자 오프라인 평가의 NDCG@10 상대 향상이다.
- **어떤 변경 때문에 좋아졌나?** 전처리·특징·학습 구성이 함께 바뀐 결과다. 특정 변경의 단독 인과 효과는 추가 통제 실험이 필요하다.
- **개인화가 충분한가?** 네 개 프로필과 조건이 같으면 같은 추천이다. 사용자의 피부 고민·취향 반응을 수집해야 더 세밀하게 구분할 수 있다.
- **다양성은 해결했나?** 한 목록 안의 브랜드 중복만 줄였다. 전체 노출 상품 수와 정확도 향상은 확인하지 못했다.
- **실제 서비스 성능도 좋아졌나?** 로컬 데모와 오프라인 검증까지 완료했다. 실제 가입자 만족도나 온라인 전환 개선은 측정하지 않았다.
